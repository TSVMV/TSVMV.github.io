## 什么是 CTF？

CTF（Capture The Flag，夺旗赛）是一种网络安全竞赛形式。参赛者需要通过各种技术手段，找到隐藏在题目中的 **Flag（旗帜）**——通常是一串特定格式的字符串，比如 `flag{this_is_a_flag}`。

CTF 起源于 1996 年的 DEFCON 全球黑客大会，如今已经成为网络安全领域最受欢迎的竞赛形式，也是学习安全技术的最佳途径之一。

## CTF 的两种主要模式

### 1. 解题模式（Jeopardy）

最常见的模式。比赛提供一系列题目，每道题有不同的分值，选手解题后提交 Flag 获得分数。分值越高，题目越难。比赛结束时总分最高的队伍获胜。

### 2. 攻防模式（Attack-Defense）

每支队伍拥有自己的服务器（上面运行着有漏洞的服务），需要同时：
- **攻击**其他队伍的服务，获取 Flag
- **防守**自己的服务，修补漏洞，防止被攻击

这种模式更接近真实的网络对抗，通常出现在高级别比赛中。

## CTF 的五大方向

### 1. Web — Web 安全

最热门、入门相对容易的方向。考察 Web 应用的各种漏洞：

- **SQL 注入**：在输入框中构造恶意 SQL 语句，读取数据库
- **XSS（跨站脚本）**：注入恶意 JavaScript，窃取用户信息
- **文件上传漏洞**：上传 webshell 获取服务器权限
- **SSRF（服务端请求伪造）**：让服务器发起请求，访问内网资源
- **反序列化漏洞**：利用序列化/反序列化机制执行代码
- **SSTI（模板注入）**：在模板引擎中注入代码
- **命令执行**：通过各种方式在服务器上执行系统命令

**入门建议**：先学 HTTP 协议、PHP 基础、JavaScript 基础，然后刷 [BUUCTF](https://buuoj.cn/) 和 [CTFHub](https://www.ctfhub.com/) 的 Web 题。

### 2. Crypto — 密码学

考察各种加密算法的理解和攻击：

- **古典密码**：凯撒密码、维吉尼亚密码、栅栏密码、培根密码等
- **RSA 攻击**：小公钥指数、共模攻击、Wiener 攻击、Coppersmith 攻击
- **AES / DES**：分组密码的各种攻击模式
- **哈希碰撞**：MD5、SHA1 的碰撞利用
- **离散对数**：Diffie-Hellman、椭圆曲线的攻击
- **格密码（Lattice）**：高级题目，涉及 LLL 算法等

**入门建议**：先学数论基础（模运算、欧拉定理、扩展欧几里得），然后学 Python 的 `gmpy2`、`sympy`、`pycryptodome` 库。

### 3. Reverse — 逆向工程

分析编译后的程序（二进制文件），理解其逻辑，找到 Flag：

- **静态分析**：用 IDA Pro、Ghidra 反编译，阅读汇编或伪代码
- **动态调试**：用 x64dbg、gdb 单步调试，观察程序运行
- **脱壳**：去除程序的加壳保护
- **反调试对抗**：绕过程序的反调试机制
- **算法还原**：逆向出程序中的加密/校验算法

**入门建议**：先学汇编语言（x86/x64）、C 语言，然后用 IDA Free 或 Ghidra（免费）做练习。

### 4. Pwn — 二进制漏洞利用

最硬核的方向。找到二进制程序中的内存漏洞，构造 payload 获取 shell：

- **栈溢出**：覆盖返回地址，控制程序执行流
- **格式化字符串漏洞**：利用 `%n` 等格式符读写任意内存
- **Heap（堆）漏洞**：Use After Free、Double Free、堆溢出等
- **ROP（返回导向编程）**：在开启 NX 保护时，用 gadget 拼接代码
- **栈迁移**：把栈搬到可控区域

**入门建议**：先学 Reverse 基础，然后学 pwntools 库，从最简单的 ret2text 开始。

### 5. Misc — 杂项

包罗万象的方向，什么都可能考：

- **隐写术**：图片、音频、视频中隐藏信息
- **流量分析**：用 Wireshark 分析 pcap 抓包文件
- **压缩包分析**：ZIP/RAR 密码破解、伪加密
- **编码转换**：各种奇奇怪怪的编码
- **内存取证**：用 Volatility 分析内存镜像
- **二维码、条形码**：各种图像中的信息提取

**入门建议**：多积累工具和经验，Misc 题很考验知识面和脑洞。

## 学习路线推荐

### 第一阶段：打基础（1-3 个月）

1. 学 Linux 基础命令和 Shell
2. 学 Python 编程（CTF 必备工具语言）
3. 学计算机网络基础（TCP/IP、HTTP）
4. 选一个方向深入（推荐 Web 或 Crypto）

### 第二阶段：刷题（3-6 个月）

1. 在 BUUCTF、CTFHub、攻防世界上刷入门题
2. 每道题做完后看 Writeup，总结知识点
3. 开始参加线上比赛（很多比赛对新手友好）

### 第三阶段：进阶（6 个月以上）

1. 深入学习所选方向的高级技术
2. 参加高质量比赛（强网杯、XCTF、picoCTF 等）
3. 尝试复现真实 CVE 漏洞
4. 写 Writeup 博客，输出倒逼输入

## 常用工具推荐

| 方向 | 工具 |
|------|------|
| Web | Burp Suite、HackBar、sqlmap、dirsearch |
| Crypto | Python（gmpy2、sympy、pycryptodome）、SageMath |
| Reverse | IDA Pro / Ghidra、x64dbg、gdb、die |
| Pwn | pwntools、gdb + pwndbg、ROPgadget、one_gadget |
| Misc | Wireshark、StegSolve、binwalk、zsteg、Volatility |
| 通用 | Docker、VMware、CyberChef、Hex Fiend |

## 推荐学习资源

- **BUUCTF**：国内最大的 CTF 刷题平台之一，题量丰富
- **CTFHub**：技能树形式，适合系统学习
- **攻防世界**：新手区适合入门
- **picoCTF**：国外面向中学生的 CTF，题目质量高
- **CTFtime**：全球 CTF 比赛日历和排名
- **看雪学院**：逆向和二进制方向的优质社区
- **先知社区**：阿里的安全社区，文章质量高

## 给新手的建议

1. **不要怕难**：CTF 题目确实有难度，但每解出一道题都会有巨大的成就感
2. **善用搜索**：遇到不会的知识点先 Google，很多题目的考点都是公开的
3. **写 Writeup**：解题后把过程写下来，既巩固知识又能帮助别人
4. **组队学习**：找几个志同道合的朋友一起打比赛，分工合作效率更高
5. **保持好奇**：CTF 的本质是探索和发现，保持好奇心是最重要的

## 总结

CTF 是学习网络安全最好的方式之一，它把枯燥的安全知识变成了有趣的解谜游戏。无论你将来想做安全研究、渗透测试、还是只是想了解黑客技术，CTF 都是一个绝佳的起点。

最重要的是**开始行动**——打开一个刷题平台，从最简单的题开始，一道一道地啃。半年后你会发现自己已经成长了很多。

祝你在 CTF 的世界里玩得开心，早日成为大佬！
