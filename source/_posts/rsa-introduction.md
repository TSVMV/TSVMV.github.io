## 什么是 RSA？

RSA 是一种**非对称加密算法**，由 Ron Rivest、Adi Shamir 和 Leonard Adleman 于 1977 年提出，名字取自三位作者的首字母。

与对称加密（加密和解密用同一个密钥）不同，RSA 使用一对密钥：

- **公钥（Public Key）**：可以公开给任何人，用于加密消息
- **私钥（Private Key）**：只有自己知道，用于解密消息

用公钥加密的内容，只能用对应的私钥解密。这就像一个公开的邮箱——任何人都可以把信投进去（公钥加密），但只有持钥匙的人才能打开取信（私钥解密）。

## RSA 的数学原理

RSA 的安全性基于一个数学难题：**大整数质因数分解**。即给定两个大质数 p 和 q，计算 n = p × q 很容易；但反过来，给定 n，找出 p 和 q 非常困难。

### 第一步：生成密钥对

1. 选择两个大质数 p 和 q
2. 计算 n = p × q
3. 计算欧拉函数 φ(n) = (p-1) × (q-1)
4. 选择整数 e，满足 1 < e < φ(n)，且 e 与 φ(n) 互质
5. 计算 d，使得 d × e ≡ 1 (mod φ(n)），即 d 是 e 在模 φ(n) 下的乘法逆元

最终：
- **公钥** = (n, e)
- **私钥** = (n, d)

### 第二步：加密

假设要加密的消息为 m（m < n），加密公式：

```
c = m^e mod n
```

其中 c 是密文。

### 第三步：解密

收到密文 c 后，用私钥解密：

```
m = c^d mod n
```

就能还原出原始消息 m。

## 一个简单的例子

我们用小数字来演示完整流程（实际使用中 p 和 q 会是几百位的大质数）：

1. 选 p = 61，q = 53
2. n = 61 × 53 = 3233
3. φ(n) = 60 × 52 = 3120
4. 选 e = 17（17 和 3120 互质）
5. 求 d：17 × d ≡ 1 (mod 3120)，计算得 d = 2753

现在加密消息 m = 65：

```
c = 65^17 mod 3233 = 2790
```

解密：

```
m = 2790^2753 mod 3233 = 65
```

成功还原！

## 为什么 RSA 是安全的？

攻击者知道公钥 (n, e)，想要解密就必须求出 d。而求 d 需要知道 φ(n) = (p-1)(q-1)，这就需要对 n 进行质因数分解。

当 n 是一个 2048 位（约 617 位十进制数）的大整数时，用目前最快的计算机和算法进行质因数分解，需要花费**数十亿年**。这就是 RSA 安全性的基础。

> 注意：随着量子计算的发展，Shor 算法可以在多项式时间内分解大整数，RSA 在量子计算机面前将不再安全。但目前实用的量子计算机还远未达到这个水平。

## RSA 的实际应用

- **HTTPS / TLS**：网站证书中的密钥交换
- **数字签名**：用私钥签名，公钥验证，确保消息不被篡改
- **SSH 登录**：密钥对认证
- **软件更新验证**：确保更新包来自官方且未被篡改

## CTF 中的 RSA 常见考点

在 CTF 比赛中，RSA 题目通常考察以下弱点：

1. **小公钥指数攻击**：e 太小（如 e=3）且未填充时，可直接开立方
2. **共模攻击**：多个用户共用同一个 n，不同 e 时可恢复明文
3. **低解密指数攻击（Wiener's Attack）**：d 太小时可通过连分数逼近恢复
4. **质因数分解**：n 不够大或 p、q 太接近时可被分解
5. **Coppersmith 攻击**：已知明文高位或低位时的攻击

## 总结

RSA 是现代密码学的基石之一，它的核心思想是利用数学上的"单向函数"——正向计算容易，反向求解困难。理解 RSA 不仅有助于学习密码学，也是参加 CTF 比赛的必备知识。

如果你对密码学感兴趣，可以进一步学习：椭圆曲线加密（ECC）、Diffie-Hellman 密钥交换、哈希函数等主题。
